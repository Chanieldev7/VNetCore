      Import

      File format guide

      VNetCore imports JSON (recommended, a complete backup) and CSV (for spreadsheets). The quickest start is to download a template, edit it, and import it.

      Rules for both formats

      • Save the file as UTF-8. The maximum size is 5 MB.
      • Up to 500 devices, and up to 512 ports per device.
      • Port status must be active, no-link, available or unknown-device.
      • Port kind must be LAN or WAN. Each kind and number appears once per device (for example, one LAN 1).
      • Review dates use YYYY-MM-DD, for example 2026-12-31.
      • Importing shows a summary first, then replaces the active project. Other projects are not changed.

      JSON

      A project object with a devices array. Only devices is required; every other field is optional.

      JSON fields
      Field Where Value
      projectName, owner Project Text, up to 120 characters
      reviewDate Project YYYY-MM-DD
      rackUnits Project Rack size: 10, 15, 20, 25, 30, 35, 40, 42, 45 or 50 (default 42)
      devices Project Array of devices (required)
      connections Project Array of links between ports
      id Device, port Unique text. Needed only to link ports.
      name, type, location Device Text
      portLayout Device alternating or split
      manufacturer, serialNumber, macAddress, managementIp, firmware, rack, notes Device Optional inventory details
      rackUnit, rackHeight Device Lowest rack unit the device uses (1–60) and its height in units (1–20, default 1). Needs a rack name.
      ports Device Array of ports
      portKind, number, status Port LAN/WAN, 1–512, a status above
      connectionType, connectedTo, vlan, address, notes Port Text
      firstDeviceId, firstPortId, secondDeviceId, secondPortId Connection IDs of two existing ports

      CSV

      The first row lists column names. Columns are matched by name, so their order does not matter and empty columns can be left blank. Each row is one record, set by recordType:

      • PROJECT: one row with projectName, projectOwner, reviewDate and projectRackUnits.
      • DEVICE: one row per device with deviceId, deviceName, deviceType, deviceLocation, portLayout and the optional deviceManufacturer, deviceSerialNumber, deviceMacAddress, deviceManagementIp, deviceFirmware, deviceNotes, deviceRack, deviceRackUnit and deviceRackHeight.
      • PORT: one row per port with the deviceId it belongs to, portId, portKind, portNumber, status, connectionType, connectedTo, vlan, address and notes.
      • To link two ports, fill linkedDeviceId and linkedPortId on one of the two PORT rows. 
      recordType,projectName,deviceId,deviceName,deviceType,portId,portKind,portNumber,status,vlan,linkedDeviceId,linkedPortId

DEVICE,,fw1,Edge firewall,Firewall,,,,,,,

      Values that contain commas or line breaks must be wrapped in double quotes. On export, values starting with = + - or @ get a leading apostrophe so spreadsheets do not run them as formulas; VNetCore removes it again on import.
